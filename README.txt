دفترچه دیجیتال آتنا
====================

محتویات:
- index.html : ساختار اصلی سایت
- style.css  : تمام ظاهر و طراحی سایت
- script.js  : تعامل‌ها و قابلیت‌های جاوااسکریپت: ستاره‌های عمق‌دار، افکت کلیک، کارت‌های سه‌بعدی، منوی موبایل، تغییر پوسته، تایپ متحرک و نوار پیشرفت
- assets/atena.jpg : عکس پروفایل شما

روش اجرا:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) وارد پوشه atena_portfolio شوید.
3) فایل index.html را با مرورگر باز کنید.

نکته:
آدرس عکس در کد به شکل نسبی assets/atena.jpg ثبت شده است؛
پس برای نمایش عکس، پوشه assets را کنار فایل index.html نگه دارید.
برای ویرایش متن‌ها، index.html را در VS Code باز کنید.
